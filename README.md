# TexasRoofCost.com

Free Texas roof replacement cost estimator. No personal info collected. Ever.

## Quick Start — No database needed

```bash
npm install
npm run dev
# Open http://localhost:5173
```

That's it. No Convex, no environment variables, no accounts needed to run locally.

## Tech Stack
- React 18 + Vite + React Router
- Zero backend dependencies for the calculator
- Convex will be added in Week 3 for analytics

## Build for production
```bash
npm run build
# Upload /dist folder to Hostinger public_html
```
